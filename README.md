# Top Menu Bar

Standard top application menu bar (File, Edit, View, Selection, Go, Run, Terminal, Help)

## Details
- **Identifier**: `matn.ext.menubar`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Top Menu Bar**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-menubar
```
